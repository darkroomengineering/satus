## State machine (as verified)

FRESH_CLONE → `bun install` → DEPS_INSTALLED → `cp .env.example .env.local` → ENV_CONFIGURED → `setup:project` (one-shot by design; self-prunes last, SIGKILL-safe, now locked + loud on failure) → INTEGRATION_STRIPPED → `handoff` (re-run-safe, now builds) → CLIENT_HANDED_OFF → deploy (CLI links first, pushes after — both docs now say so).

One-way transitions that stay one-way by design: `setup:project` self-prune (escape: git history, now stated by the stub), handoff's branding removal (escape: the gitignored `README.original.md` backup). These are starter-appropriate irreversibilities, now self-describing instead of silent.

## What held up (no findings)

Env validation errors (model-quality: name the variable, dev and build both); rate limiting end-to-end (both limiters, correct `Retry-After`, real window reset); webhook auth paths (503/401 exactly as documented); `--dry-run` (byte-zero mutation, accurate plan); preflight-first/self-prune-last under SIGKILL; the H5 re-run backup guard; `check:assets` and `manifest:check` (exemplary exit-code and stderr discipline); doc routing for "add a Shopify page" (2 hops) and "add an integration" (1 hop).

## Considered & rejected

- P-D4 fixed in-repo — rejected: the "warning" string is oxlint's own output; patching presentation would drift from upstream. Exit codes are the agent contract, now documented by outcome.
- Making `setup:project` reversible — rejected: one-shot is the create-darkroom contract's design; the friendly stub + git-history pointer is the right cost.
- Non-interactive `handoff` flag surface — deferred, not rejected: EOF fails loudly (exit 1) instead of lying (`setup:project` in #370; `generate`/`handoff` completed later); a full flag surface is a feature, not a defect fix.
- The walker-reported "cascade-layer test failure in rsync copies" — environmental artifact of copied generated CSS state; passes in every real clone; not a finding.
